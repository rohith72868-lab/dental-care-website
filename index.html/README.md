# BrightBite Dental Clinic — Premium Website

A complete, high-converting dental clinic website built with a luxury-medical aesthetic, clean white & soft mint/deep teal color palette, elegant serif typography, rounded organic shapes, realistic dental photography, and conversion-focused CTAs.
